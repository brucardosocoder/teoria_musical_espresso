Funções Harmônicas e Cadências

A Harmonia Funcional

A Harmonia Funcional é o estudo de como os acordes se relacionam entre si dentro de uma tonalidade (Campo Harmônico - Dose 6) e como eles criam um senso de movimento, tensão e repouso na música.

Cada acorde no Campo Harmônico possui uma Função Harmônica primária, que define seu papel na progressão:

Função Papel Acordes Principais (Maiores) Acordes Substitutos (Maiores)
Tônica (T) Repouso, Estabilidade, Centro Tonal I III, VI
Subdominante (SD) Movimento, Preparação para a Dominante IV II
Dominante (D) Tensão, Necessidade de Resolução para a Tônica V VII°

Cadências: O Fim de uma Frase Musical

Cadência é a sequência de acordes que conclui uma frase ou seção musical, criando um senso de repouso ou suspensão. É o "ponto final" ou a "vírgula" da música.

As cadências são classificadas de acordo com o grau de resolução que proporcionam:

1. Cadência Perfeita (V → I)

  • Definição: É a cadência mais forte e conclusiva. O acorde de Dominante (V) resolve para o acorde de Tônica (I).
  • Sensação: Repouso total, conclusão. É o "ponto final" definitivo.
  • Exemplo (Dó Maior): G → C (Sol Maior para Dó Maior).

2. Cadência Imperfeita (V → I, com inversão ou melodia no baixo)

  • Definição: Também é V → I, mas com um dos acordes (ou ambos) em inversão, ou com a melodia terminando em uma nota diferente da tônica.
  • Sensação: Repouso, mas menos definitivo que a Perfeita. É um "ponto final" mais suave.

3. Cadência Plagal (IV → I)

  • Definição: O acorde de Subdominante (IV) resolve para o acorde de Tônica (I).
  • Sensação: Repouso suave, frequentemente associada a hinos religiosos ("Amém").
  • Exemplo (Dó Maior): F → C (Fá Maior para Dó Maior).

4. Meia Cadência (Qualquer Acorde → V)

  • Definição: A progressão termina no acorde de Dominante (V).
  • Sensação: Suspensão, tensão. Cria uma expectativa de que a música continuará. É uma "vírgula" ou "ponto de interrogação".
  • Exemplo (Dó Maior): C → G (Dó Maior para Sol Maior).

5. Cadência Enganosa (V → VI)

  • Definição: O acorde de Dominante (V) resolve para o acorde Submediante (VI) em vez do esperado I.
  • Sensação: Surpresa, desvio. O ouvido espera a resolução para a Tônica (I), mas é "enganado" pela resolução para o VI (que tem função Tônica).
  • Exemplo (Dó Maior): G → Am (Sol Maior para Lá Menor).
