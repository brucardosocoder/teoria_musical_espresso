½

Semitom

O semitom (ou meio tom) é a menor distância possível entre duas notas na escala cromática.

Exemplos de Semitons:

  • Dó para Dó#: Semitom cromático (mesmo nome)
  • Mi para Fá: Semitom diatônico (nomes diferentes)
  • Si para Dó: Semitom diatônico (nomes diferentes)

No Teclado:

Um semitom é o movimento de uma tecla para a tecla imediatamente adjacente, seja ela branca ou preta.

Tom (Tom Inteiro)

O tom (ou tom inteiro) é a distância equivalente a dois semitons.

Exemplos de Tons:

  • Dó para Ré: Tom (C → C# → D)
  • Fá# para Sol#: Tom (F# → G → G#)
  • Lá para Si: Tom (A → A# → B)

Estrutura:

Semitom + Semitom = Tom

A Escala Maior:

T-T-S-T-T-T-S

A importância do tom e do semitom se manifesta claramente na construção das escalas. A Escala Maior é o modelo fundamental da música ocidental.

Fórmula da Escala Maior:

Esta sequência é a "receita" para construir qualquer escala maior, começando de qualquer nota.

Escala de Dó Maior

Nota Intervalo

Dó (C) —

Características

  • 8 notas no total (incluindo a oitava)
  • 5 tons e 2 semitons
  • Semitons ocorrem entre o 3º e 4º graus (Mi-Fá) e entre o 7º e 8º graus (Si-Dó)
  • Padrão universal para todas as escalas maiores
